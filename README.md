# КОНТУР — Barbershop / Portfolio Concept

Профессиональный демонстрационный лендинг барбершопа для портфолио. Проект не является сайтом действующей компании.

## Возможности
- Адаптивная editorial-сетка, типографика, галерея и прайс
- Выбор услуги из прайса и всплывающая демонстрационная форма записи
- Закрытие окна по Escape, фокус внутри диалога, мобильное меню
- Без сборщиков и зависимостей: HTML, CSS, JavaScript
- Снижение анимации при `prefers-reduced-motion`

## Важно
Форма **не отправляет** данные и не создаёт реальную бронь. Цены, часы работы и адрес условные. Фотографии в CSS загружаются с images.unsplash.com и требуют интернета. Шрифты Google Fonts также загружаются из интернета; указаны системные запасные шрифты.

## Публикация на GitHub Pages
1. Загрузите все файлы из папки в корень репозитория (рядом с `index.html`).
2. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Адрес: `https://USERNAME.github.io/REPOSITORY/`.

## Подход к дизайну
Принципы UI UX Pro Max (типографическая иерархия, контраст, ясные CTA, доступность) и визуальный подход 21st.dev (качественные секции и компоненты) применены как ориентиры. Сторонние скиллы и компоненты 21st.dev в исходники не устанавливались.
